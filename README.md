### Option Command

#### 指令组成

标准操作指令共八位，形式如下：`#1P1T100`，其中

1. `#`号后接设备号

2. `P`后接操作类型
3. `T`后参数暂无实际含义
4. 在esp32中，取值和操作类型均以字符形式存储

#### `#`设备号含义对照

| 取值 | `1`    | `3`    | `2`      | `4`      | `0/7`    | `R`            | `W`            | `E`                |
| ---- | ------ | ------ | -------- | -------- | -------- | -------------- | -------------- | ------------------ |
| 含义 | 左电机 | 右电机 | 左电磁铁 | 右电磁铁 | 结束指令 | data_sheet读取 | data_sheet写入 | data_sheet结束写入 |

#### `P`操作类型含义对照 

1. 电机

   | 取值 | `3`            | `4`            | `5`       | `6`            | `7`            | `8`       |
   | ---- | -------------- | -------------- | --------- | -------------- | -------------- | --------- |
   | 含义 | 顺时针轻微转动 | 逆时针轻微转动 | 转动360度 | 顺时针转动90度 | 逆时针转动90度 | 转动180度 |

2. 电磁铁

   | 取值 | `0`  | `1`  | `6`      | `7`      | `9`      |
   | ---- | ---- | ---- | -------- | -------- | -------- |
   | 含义 | 打开 | 吸合 | 全部吸合 | 全部打开 | 持久吸合 |

#### data_sheet指令

因参数传递需要，指令类型略有不同，为`#XABCCCC`

1. `A`为参数类别

2. `B`为参数编号

3. `C`为参数值

4. 类别与编号见下表

   | 参数编号 | `0`：延时类        | `1`：脉冲类        | `2`：加速度曲线类 |
   | -------- | ------------------ | ------------------ | ----------------- |
   | 0        | 电磁铁闭合延时     | 左电机定位补偿脉冲 | 空转加速脉冲      |
   | 1        | 电磁铁打开延时     | 右电机定位补偿脉冲 | 带转加速脉冲      |
   | 2        | 持久吸合时吸合延时 |                    | 拧动加速脉冲      |
   | 3        | 持久吸合时打开延时 |                    | DEBUG加速脉冲     |
   | 4        | 连续转动延时       |                    |                   |
   | 5        | 电机初始化速度延时 |                    |                   |
   | 6        | 电机Debug速度延时  |                    |                   |
