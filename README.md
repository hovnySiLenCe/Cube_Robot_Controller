## Operation Command

指令集的组成有两部分，一个是上位机控制下位机的控制指令集1，另一个是data_sheet读取和写入的指令集2。

### 控制指令集1

#### 上位机向下位机发送的控制命令

下位机时刻处于接收和执行状态，等待上位机的控制指令

上位机控制指令共8位，形式如下：`#1P1T100`，其中

1. `#`号后接设备号
2. `P`后接操作类型
3. `T`后参数暂无实际含义
4. 在下位机中，取值和操作类型均以字符形式存储

##### `#`设备号含义对照

| 取值 | `1`    | `2`      | `3`    | `4`      | `0/7`    | `8`  | `9`  |
| ---- | ------ | -------- | ------ | -------- | -------- | ---- | ---- |
| 含义 | 左电机 | 左电磁铁 | 右电机 | 右电磁铁 | 结束指令 | 失能 | 复位 |

##### `P`操作类型含义对照

1. 电机

   | 取值 | `3`            | `4`            | `5`       | `6`            | `7`            | `8`       |
   | ---- | -------------- | -------------- | --------- | -------------- | -------------- | --------- |
   | 含义 | 顺时针轻微转动 | 逆时针轻微转动 | 转动360度 | 顺时针转动90度 | 逆时针转动90度 | 转动180度 |

2. 电磁铁

   | 取值 | `0`  | `1`  | `6`      | `7`      | `9`      |
   | ---- | ---- | ---- | -------- | -------- | -------- |
   | 含义 | 打开 | 吸合 | 全部吸合 | 全部打开 | 持久吸合 |

### 数据表指令集2
为了实现参数的传递与通讯，针对数据表开发了数据表指令集2（其实可以使用Json传递，这样子读写更加方便，但是受限于原框架，这里选择使用和控制指令集1类似的指令集）。

#### 上位机向下位机发送的指令

功能包括：读取`#R000000`，写入`#WABCCCC`，保存`#E000000`

其中写入指令的含义如下：

1. `A`为参数类别

2. `B`为参数编号

3. `C`为参数值

4. 类别与编号见下表

   | 参数编号 | `0`：延时类        | `1`：脉冲类        | `2`：加速度曲线类 |
   | -------- | ------------------ | ------------------ | ----------------- |
   | 0        | 电磁铁闭合延时     | 左电机定位补偿脉冲 | 空转加速脉冲      |
   | 1        | 电磁铁打开延时     | 右电机定位补偿脉冲 | 带转加速脉冲      |
   | 2        | 持久吸合时吸合延时 | 旋转90度脉冲数  | 拧动加速脉冲      |
   | 3        | 持久吸合时打开延时 | 旋转180度脉冲数 | DEBUG加速脉冲     |
   | 4        | 连续转动延时       | 旋转360度脉冲数 |                   |
   | 5        | 电机初始化速度延时 |                    |                   |
   | 6        | 电机Debug速度延时  |                    |                   |

#### 下位机向上位机发送的指令

##### 数据读取

当上位机发起读取请求时，下位机会按照`#DSABCCCC`的指令格式发送参数内容，其中各参数的含义是

1. `#DS`表示数据开头，该指令和DataSheet有关
2. `A`为参数类别
3. `B`为参数编号
4. `C`为参数值（范围在0-9999）

#### 读取结束标记

当读取结束后，下位机会发送`#DSEND`标志读取结束，上位机收到信号后会更新UI界面的参数值

#### 参数的存储格式

在上下位机中，参数均以结构体的形式存储，以下位机为例

```C++
#define MAX_KEY_NUM 30
struct Data_Sheet_t {
    unsigned short key[MAX_KEY_NUM]; // 数据表结构体
    Data_Sheet_t() {
    key[MAGNET_TIGHT_DELAY_ID] = 50; // 单位ms
    key[MAGNET_LOOSE_DELAY_ID] = 111;

    key[MAGNET_TIGHT_RATIO_DELAY_ID] = 5; // 单位ms
    key[MAGNET_LOOSE_RATIO_DELAY_ID] = 15;

    key[MAGNET_DELTA_DELAY_ID] = 5;
    key[CONTINOUS_TWIST_DELAY_ID] = 10; // 连续拧动的延迟，单位ms

    key[STEPPER_REVERSE_DELAY_ID] = 5000; // 初始位置延迟，单位us
    key[STEPPER_DEBUG_DELAY_ID] = 5000; // 轻微延迟，单位us

    // ----------- 脉冲数设置 -----------
    key[STEPPER_L_CORRECTION_ID] = 39; // 补偿脉冲
    key[STEPPER_R_CORRECTION_ID] = 42;

    key[PULSE_360_ID] = 2000; // 360度转动的脉冲数
    key[PULSE_180_ID] = 1000; // 180度转动的脉冲数
    key[PULSE_90_ID] = 500;   // 90度转动的脉冲数
    key[DELTA_PULSE_ID] = 1;  // 轻微转动的脉冲数

    // S型曲线加速度步数
    key[ACC_PULSE_OF_RACE_ID] = 50;
    key[ACC_PULSE_OF_TURN_ID] = 75;
    key[ACC_PULSE_OF_TWIST_ID] = 50;
    key[ACC_PULSE_OF_DEBUG_ID] = 50;
    }
}
```

使用一维数据的方式存储，参数具有较好的连续性
